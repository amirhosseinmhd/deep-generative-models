# Deep Generative Models

This repository contains implementations of three fundamental generative models developed as part of a Deep Generative Modelling course.

## Contents

### 1. GANs (Generative Adversarial Networks)
Located in `Q1_GANs/`

Implementation of Generative Adversarial Networks, demonstrating the adversarial training process between a generator and discriminator network.

- `1D Example.ipynb`: 1D GAN implementation
- `Untitled26.ipynb`: Main GAN implementation

### 2. VAEs (Variational Autoencoders)
Located in `Q2_VAEs/`

Implementation of Variational Autoencoders, showcasing probabilistic encoding and decoding with latent variable models.

- `VAE.ipynb`: VAE implementation
- `Summary_VAE.pdf`: Summary and documentation

### 3. Diffusion Models
Located in `Q3_Diffusion/`

Implementation of Diffusion Models, demonstrating the denoising diffusion probabilistic approach to generation.

- `Diffusion.ipynb`: Diffusion model implementation
- Visualization examples included

## Requirements

- Python 3.x
- PyTorch
- NumPy
- Matplotlib
- Jupyter Notebook

## Usage

Each model is contained in its own directory with Jupyter notebooks that can be run independently.

```bash
cd Q1_GANs  # or Q2_VAEs or Q3_Diffusion
jupyter notebook
```
